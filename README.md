# Multi-Site Enterprise Network Implementation
A robust multi-site network architecture designed and simulated in Cisco Packet Tracer, focusing on secure inter-site communication and dynamic routing optimization.

## 🛠️ Technologies Used
* **Cisco Packet Tracer**
* **OSPF (Open Shortest Path First)** - Implemented for dynamic routing and routing loop prevention.
* **IPsec VPN** - Configured for secure, encrypted communication across sites.

## 📌 Project Overview
* Designed a scalable network topology connecting multiple branch locations.
* Resolved routing loop issues by implementing OSPF protocols efficiently.
* Secured data transmission between sites using IPsec tunneling.
